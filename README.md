# 🍁 Maple Leaf — Backend

REST API и сервер статики для платформы **Maple Leaf** — сайта мультсериалов. Обслуживает публичный сайт (`maple-leaf-front`) и админ-панель (`maple-leaf-admin`).

---

## 📖 О проекте

Backend предоставляет API для:

- Авторизации редакции (JWT)
- Управления мультсериалами, сезонами, сериями, озвучками и новостями
- Загрузки медиафайлов (постеры, превью, видео)
- Отдачи загруженных файлов через статику `/uploads/*`

Написан на **NestJS** с модульной архитектурой: каждая бизнес-область — отдельный модуль со своим контроллером, сервисом, DTO и Mongoose-схемой.

---

## 🛠 Стек

 **NestJS** - Фреймворк 
 **TypeScript**  - Язык
 **MongoDB + Mongoose** -База данных 
 **Passport + JWT**  - Авторизация 
 **bcryptjs** - Хеширование паролей 
 **class-validator + class-transformer** -Валидация DTO 
 **@nestjs/swagger** - Документация API 
 **multer** - Загрузка файлов 
 **slugify** -Генерация URL-slug
